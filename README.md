# javascript-lotto-precourse

# 로또 게임

## 프로젝트 개요
간단한 로또 발매기를 구현하는 프로젝트입니다. 사용자는 금액을 입력하여 로또를 구매하고, 당첨 번호와 비교하여 당첨 내역 및 수익률을 확인할 수 있습니다.

## 기능 목록

### 로또 발행 기능
- 구입 금액을 입력받는다.
- 입력받은 금액을 1,000으로 나누어 발행할 로또 개수를 계산한다.
- 계산된 개수만큼 로또를 발행한다.
- 각 로또는 1부터 45까지의 숫자 중 중복되지 않는 6개의 숫자로 구성된다.
- 발행된 로또의 개수를 출력한다.
- 각 로또의 번호를 오름차순으로 정렬하여 출력한다.

### 당첨 번호 입력 기능
- 당첨 번호 6개를 쉼표(,)로 구분하여 입력받는다.
- 입력받은 문자열을 파싱하여 숫자 배열로 변환한다.
- 보너스 번호 1개를 입력받는다.

### 당첨 결과 확인 기능
- 구매한 각 로또와 당첨 번호를 비교한다.
- 일치하는 번호의 개수를 계산한다.
- 보너스 번호 일치 여부를 확인한다. (5개 일치 시 2등/3등 구분용)
- 일치 개수와 보너스 번호 일치 여부를 기반으로 당첨 등수를 판별한다.
  - 1등: 6개 번호 일치 / 2,000,000,000원
  - 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
  - 3등: 5개 번호 일치 / 1,500,000원
  - 4등: 4개 번호 일치 / 50,000원
  - 5등: 3개 번호 일치 / 5,000원

### 당첨 통계 출력 기능
- 각 등수별 당첨 개수를 집계한다.
- 5등부터 1등까지 순서대로 당첨 내역을 출력한다.
- 각 등수의 당첨 금액과 당첨 개수를 함께 출력한다.

### 수익률 계산 기능
- 총 당첨 금액을 계산한다. (각 등수 당첨금 × 당첨 개수의 합)
- 수익률을 계산한다. (총 당첨 금액 / 구입 금액 × 100)
- 수익률을 소수점 둘째 자리에서 반올림하여 출력한다.

## 예외 상황

### 구입 금액 예외
- 구입 금액이 숫자가 아닌 경우
- 구입 금액이 1,000원으로 나누어떨어지지 않는 경우
- 구입 금액이 1,000원 미만인 경우

### 로또 번호 예외
- 로또 번호의 개수가 6개가 아닌 경우
- 로또 번호가 1~45 범위를 벗어나는 경우
- 로또 번호에 중복된 숫자가 있는 경우

### 당첨 번호 예외
- 당첨 번호의 개수가 6개가 아닌 경우
- 당첨 번호가 1~45 범위를 벗어나는 경우
- 당첨 번호에 중복된 숫자가 있는 경우
- 당첨 번호가 쉼표로 구분되지 않은 경우
- 당첨 번호에 숫자가 아닌 값이 포함된 경우

### 보너스 번호 예외
- 보너스 번호가 숫자가 아닌 경우
- 보너스 번호가 1~45 범위를 벗어나는 경우
- 보너스 번호가 당첨 번호와 중복되는 경우

### 공통 예외 처리
- 모든 예외 메시지는 "[ERROR]"로 시작한다.
- 예외가 발생하면 해당 지점부터 입력을 다시 받는다.
